# MAX UPGRADER — концепт

Апгрейдер (как CS:GO-апгрейдеры) в визуальном стиле мессенджера MAX.
Одна кодовая база → **web + APK (Android) + EXE (Windows)**.

Валюта — **виртуальная**, никаких реальных денег, доната и вывода. Это игра-симулятор.

---

## 1. Идея и обёртка

Приложение выглядит не как казино-сайт, а как **мессенджер**. Игра живёт внутри
«мини-приложения» и чата с ботом.

Нижний таб-бар (как в MAX):

| Таб | Что внутри |
|---|---|
| 💬 Чаты | чат с `MAX Upgrader Bot` — каждый апгрейд приходит сообщением в чат; канал «Дропы»; чат «Поддержка» с FAQ |
| 🎮 Игры | сетка мини-игр: Апгрейд, Кейсы, Контракт, Мины, Краш, Битва |
| 🎒 Инвентарь | предметы, продажа, «отправить в чат» |
| 👤 Профиль | баланс, уровень, статистика, достижения, настройки, Provably Fair |

**Фишка №1 — чат как лог игры.** Крутанул апгрейд → в чате появляется пузырь:

```
Bot                           14:32
┌──────────────────────────────┐
│ 🎰 Апгрейд x4.8              │
│ Ставка: 250 MX               │
│ Шанс: 19.4%                  │
│ ▸ ВЫИГРЫШ  +1 200 MX         │
│ 🎁 Золотой ник               │
└──────────────────────────────┘
                        [Повторить]
```

Сообщения с галочками ✓✓, «Bot печатает…» во время прокрутки колеса,
реакции на крупные выигрыши, ответ-свайп «Повторить ставку».

**Фишка №2 — канал «Дропы»** — лента чужих выигрышей (боты с рандомными
никами/аватарами), формат постов канала с просмотрами и реакциями. Создаёт
ощущение живого сервиса без сервера.

## 2. Механики

### 2.1 Апгрейд (ядро)
- Слева — что ставишь (баланс или предмет из инвентаря), справа — цель
  (предмет или чистый множитель).
- Слайдер множителя **x1.05 … x50**.
- Шанс: `chance = (bet / target) * RTP`, RTP по умолчанию **0.92**.
- Колесо: круг, зелёный сектор = шанс, стрелка разгоняется 3.5 с и тормозит
  с ease-out. Победа → сектор пульсирует, конфетти, вибрация.
- **Режим DOWN (обратный апгрейд)**: ставишь на то, что стрелка НЕ попадёт в
  сектор. Маленький множитель, большой шанс. Переключатель UP/DOWN.
- Быстрый режим (без анимации) для гринда.
- Автоапгрейд: N спинов, стоп при балансе < X или при выигрыше > Y.

### 2.2 Кейсы (стикерпаки)
- Кейс = набор предметов с весами. Открытие — горизонтальная лента, которая
  тормозит на предмете (классика). Мульти-открытие ×2/×3/×5.
- Кейсы: «Стартовый», «Стикерпак», «Премиум», «Канал», «Легендарный».

### 2.3 Контракт
- Кидаешь 3–10 предметов → получаешь один. Ожидание = 0.9 × сумма,
  разброс ±(30…90)% по треугольному распределению. Визуал — предметы
  всасываются в центр.

### 2.4 Мины
- Сетка 5×5, выбираешь число мин (1–24), открываешь клетки, множитель растёт,
  «Забрать» в любой момент. Формула честная: произведение (осталось безопасных).

### 2.5 Краш
- График летит вверх, множитель растёт экспоненциально, нужно успеть забрать.
  Точка краша считается provably fair. Рядом — фейковые игроки в списке.

### 2.6 Битва кейсов
- 1v1 / 2v2 против ботов, открываем кейсы одновременно, кто набрал больше —
  забирает всё. Визуал — как групповой чат с результатами.

### 2.7 Экономика и анти-слив
- Старт: **1 000 MX**.
- Ежедневный бонус + стрик (7 дней = х3).
- «Колесо дня» — 1 бесплатный спин раз в 8 часов.
- «Спасательный круг»: если баланс = 0 → 100 MX через 15 минут, без лимита.
- Промокоды (локальный список, легко дописывать).
- XP за каждую игру → уровни → титулы, рамки аватара, новые кейсы.

### 2.8 Предметы (вместо скинов)
Тематика — статусы и подарки мессенджера:
`Синяя галочка`, `Стикерпак «Котик»`, `Золотой ник`, `Анимированный аватар`,
`Премиум 1 мес`, `Канал 1К подписчиков`, `Канал 1М`, `Тёмная тема Pro`,
`Кастомный звук`, `Ник без цензуры`, `Плашка «Разработчик»`…
5 редкостей: серый / синий / фиолетовый / розовый / золотой (как в тех самых
кейсах), у золотых — анимированный градиент и блик.

### 2.9 Provably Fair (честность)
- Цепочка seed'ов: `serverSeed[n] = SHA256(serverSeed[n+1])`, хэш показан заранее.
- `roll = HMAC_SHA256(serverSeed, clientSeed + ":" + nonce)` → первые 8 hex →
  число [0,1).
- Клиентский seed меняется руками в профиле.
- Экран «Проверка честности»: история раундов, кнопка «Проверить» +
  раскрытый seed прошлой цепочки. Работает полностью офлайн.

### 2.10 Прочее
- Достижения (30+), лидерборд (локальный + боты), статистика (винрейт,
  лучший множитель, всего прокручено), звук + haptics, светлая/тёмная тема,
  экспорт/импорт профиля одним кодом.

## 3. Визуальный стиль MAX

- Светлая тема: фон `#FFFFFF`, подложка `#F2F3F5`, текст `#0A0A0A`,
  вторичный `#8E8E93`.
- Акцент — фиолетово-синий градиент (примерно `#7C5CFF → #3F8CFF`),
  им же залиты кнопки, свои пузыри в чате, активный таб.
- Тёмная тема: `#111214` / `#1C1D21`.
- Скругления 16–22 px, карточки без тяжёлых теней, крупный жирный заголовок
  экрана, свайп-навигация, bottom sheet вместо модалок.
- Шрифт Inter / системный SF Pro / Roboto.
- Логотип и точные фирменные цвета MAX — **нужны твои ассеты**; по умолчанию
  рисуем свой знак «MU» в похожей стилистике, чтобы не копировать чужой бренд.

## 4. Технологии и сборка

```
max-upgrader/
├─ src/              React 18 + TypeScript + Vite, zustand, framer-motion
├─ electron/         main + preload → electron-builder → .exe (NSIS + portable)
├─ android/          Capacitor 7 → Gradle → .apk (release, подписанный)
├─ public/
└─ .github/workflows/build.yml
```

- Игра — **чистый фронтенд**, без сервера: работает офлайн, ничего не
  хостим, APK и EXE самодостаточны.
- Сохранение: localStorage (web/exe) + Capacitor Preferences (android).
- CI: GitHub Actions
  - `ubuntu-latest` → Java 21 + Android SDK → `app-release.apk`
  - `windows-latest` → electron-builder → `Max-Upgrader-Setup.exe` + portable
  - оба артефакта складываются в **Releases**, качаешь по ссылке.
- Локально из этого контейнера Windows-exe не собрать (нужен Windows-раннер),
  поэтому финальные файлы забираем из Actions/Releases — это рабочий путь.
