# План серверной версии

Объём согласован полностью: аккаунты и облачный прогресс, экономика
на сервере, реальные битвы с возможностью добить лобби ботами,
полноценная админка.

## Что уже решено

- **Вход:** логин и пароль как основа. Вторым — VK ID или Google
  (см. «Открытые вопросы»).
- **Хостинг:** VPS в РФ, порядок 200–300 ₽/мес. Postgres в Docker
  на том же сервере, управляемая база на старте не нужна.
- **Почему в РФ:** с появлением логина и почты начинаем хранить
  персональные данные, по 152-ФЗ их база должна лежать в России.

## Стек

| Слой | Чем |
|---|---|
| Сервер | Node 22, Fastify, TypeScript |
| База | PostgreSQL 16 в Docker, миграции через Prisma |
| Реальное время | WebSocket (`ws`), комнаты под лобби и общую ленту |
| Сессии | JWT: короткий access +длинный refresh в httpOnly |
| Пароли | argon2id |
| Прокси | nginx, сертификат Let's Encrypt |
| Деплой | GitHub Actions по пушу в ветку, сборка образа и рестарт |
| Админка | отдельное SPA на том же домене, `/admin` |

## Принцип защиты от накрутки

Клиент не считает ничего, что влияет на деньги. Ставка — это запрос
к серверу, сервер берёт свой сид, считает результат, меняет баланс
и возвращает клиенту, что нарисовать. Проверка честности остаётся:
хэш серверного сида выдаётся заранее, сид раскрывается при смене
цепочки, раунды пишутся в `Round`.

Клиентская анимация не должна «решать» результат — она его
воспроизводит.

## Этапы

### 1. Аккаунты и облачный прогресс
Регистрация, вход, refresh-токены, перенос локального сохранения
в облако при первом входе. Профиль, инвентарь, статистика на сервере.
Живая лента дропов и счётчик онлайна — настоящие. Глобальный
лидерборд.

### 2. Экономика на сервере
Все одиннадцать режимов переезжают в API. Клиент шлёт ставку,
получает результат и рисует. Сиды, нонсы и история раундов — на
сервере. Локальный режим остаётся отдельной песочницей без синка.

### 3. Реальные битвы и джекпот
Лобби с таймером ожидания. Не набралось людей за N секунд — места
занимают боты, игра начинается. Джекпот раундами по таймеру,
участники видят друг друга.

### 4. Полноценная админка
Игроки: поиск, баланс, инвентарь, уровень, бан. Промокоды с лимитом
активаций, сроком, привязкой к игроку и **отзывом**. Живая
статистика: онлайн, оборот, фактический RTP по каждой игре, крупные
выигрыши. Журнал действий админа.

## Открытые вопросы

1. **Что делать без сети.** Сейчас APK и EXE полностью офлайновые.
   После второго этапа экономика живёт на сервере. Варианты:
   - без сети играть нельзя, показываем экран «нет связи»;
   - остаётся отдельный офлайн-профиль, который никогда не
     синхронизируется и не попадает в лидерборд.

   Второй вариант дружелюбнее, но это две экономики в одном
   приложении и вдвое больше кода на стыке.

2. **Второй способ входа:** VK ID или Google. У Google два подвоха —
   он не работает во встроенном WebView (нужен нативный плагин или
   системный браузер) и требует Google Play Services на устройстве.
   VK ID свободен от обоих.

3. **Судьба текущего прогресса.** У тебя уже 37 уровень на телефоне.
   При первом входе переносим локальное сохранение в облако — один
   раз, с подтверждением.

## Что нужно от владельца перед стартом

1. VPS: IP, доступ по SSH, домен.
2. Решение по второму входу.
3. Если Google — `Client ID` для Android и для веба из Google Cloud
   Console, плюс SHA-1 отпечаток релизного keystore.
