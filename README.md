# MAX Upgrader

Игра-апгрейдер в визуальном стиле мессенджера MAX. Одна кодовая база —
**веб + APK (Android) + EXE (Windows)**.

Валюта в игре виртуальная (MX). Реальных денег, покупок и вывода средств нет.

## Что внутри

Приложение выглядит как мессенджер: нижний таб-бар, чаты, канал, bottom sheets,
светлая и тёмная темы.

| Раздел | Что делает |
|---|---|
| 🏠 Главная | живая лента дропов всех игроков, баннер, карусель режимов, витрина кейсов, прогресс уровня |
| 🎮 Игры | 11 режимов: Апгрейд, Кейсы, Мины, Краш, Контракт, Битва кейсов, Дабл, Кости, Башня, Слоты, Джекпот, плюс Колесо дня |
| 🎁 Кейсы | все 12 кейсов отдельным разделом |
| 🎒 Инвентарь | предметы, продажа (90% цены), отправка в чат |
| 💬 Чаты | чат с ботом, куда сообщением приходит результат каждого раунда; канал «Дропы» |

Профиль открывается по аватару в шапке, бонусы (дейлик, колесо, промокоды,
спасательный круг) — по кнопке «+» рядом с балансом.

### Механики

- **Апгрейд** — колесо с сектором шанса. `шанс = 92% ÷ множитель`,
  множитель x1.05 … x50 или «на конкретный предмет». Есть автоспин и быстрый режим.
  Награда одна: в режиме множителя — MX на баланс, в режиме предмета — предмет
  в инвентарь.
- **Кейсы** — 12 кейсов от Стартового за 60 MX до Божественного за 1 270 000 MX,
  RTP каждого 89–93%, мульти-открытие ×1/×2/×3/×5, экран с точными шансами дропа.
  Из кейса выпадает предмет; деньги за него даёт продажа в инвентаре (90% цены).
- **Мины** — поле 5×5, 1–24 мины, множитель растёт с каждой открытой клеткой,
  вывод в любой момент (RTP 97%).
- **Краш** — график растёт, нужно успеть забрать; есть автовывод (RTP 95%).
- **Контракт** — 3–10 предметов сплавляются в один, результат 25–350% от ожидания.
- **Битва кейсов** — против 1–3 ботов, победитель забирает все выпавшие предметы.
- **Дабл** — 15 слотов: 7 красных, 7 чёрных, 1 зелёный. x2 и x14, RTP 93.3%.
- **Кости** — слайдер порога 2…98, «больше» или «меньше», множитель до x47, RTP 95%.
- **Башня** — 8 этажей по 3 клетки, 1 или 2 мины в ряду, вывод на любом этаже, RTP 97%.
- **Слоты** — 3 барабана, 7 символов, джекпот 🦄🦄🦄 на x2000, RTP 92.2%.
- **Джекпот** — банк с 1–5 ботами, шанс равен доле ставки, комиссия 8%.
- **Колесо дня** — бесплатный спин раз в 8 часов.
- **Прогрессия** — 40 достижений, уровни с титулами, ежедневный бонус со стриком,
  **52 промокода** (часть выдаёт предметы, а не MX), спасательный круг при нулевом балансе.
- **Предметы** — 76 штук в 6 редкостях: обычный, редкий, эпический, мифический,
  легендарный, божественный. От стикера за 30 MX до «Ключа от всего» за 6 800 000.

### Честная игра (provably fair)

Серверный сид фиксируется заранее, показывается его SHA-256 хэш. Результат раунда:

```
roll = HMAC_SHA256(serverSeed, clientSeed + ":" + nonce + ":" + cursor)
       первые 8 hex-символов / 2^32   →   число [0, 1)
```

Клиентский сид меняется вручную; при смене раскрывается предыдущий серверный сид,
и любой раунд можно пересчитать в калькуляторе внутри приложения
(Профиль → Честная игра). SHA-256 и HMAC реализованы в проекте синхронно и сверены
с `node:crypto`.

## Сборка

```bash
npm install
npm run dev          # веб-версия на localhost:5173
npm run build        # прод-сборка в dist/
```

### EXE (Windows)

```bash
npm run electron:build      # release/MAX-Upgrader-1.0.0-x64.exe (установщик)
                            # release/MAX-Upgrader-1.0.0-portable.exe
```

Собирается на Windows. На Linux нужен `wine` (+ `wine32`), иначе используйте CI.

### APK (Android)

Нужны JDK 21 и Android SDK (`ANDROID_HOME`).

```bash
npm run android:build       # android/app/build/outputs/apk/release/app-release.apk
```

Без `android/keystore.properties` собирайте отладочный вариант —
`cd android && ./gradlew assembleDebug`.

### Подпись релизного APK

Ключ в репозиторий не коммитится. Создайте свой:

```bash
keytool -genkeypair -v -keystore android/release.keystore \
  -alias maxupgrader -keyalg RSA -keysize 2048 -validity 10950
```

и рядом `android/keystore.properties`:

```properties
storeFile=../release.keystore
storePassword=...
keyAlias=maxupgrader
keyPassword=...
```

## Где считается игра

Без аккаунта — на устройстве, как раньше. С аккаунтом раунд считает сервер:
клиент присылает только параметры ставки и получает готовый исход. Списание,
бросок, начисление, запись раунда и достижения идут одной транзакцией, а
условие на баланс стоит внутри самого UPDATE, поэтому параллельные запросы
не спишут больше, чем есть.

Математика у обоих режимов одна: общее ядро лежит в `server/src/core`, а
`src/core` подключает те же файлы. Двух копий формул не существует.

Мины, башня и краш держат раскладку на сервере в таблице `LiveRound` —
игрок узнаёт только то, что открыл сам. Краш вдобавок сверяет заявленный
множитель со временем от старта, а брошенный раунд закрывается сам, когда
расчётное время взрыва прошло.

Кулдауны бонусов, стрик и достижения тоже серверные: часы телефона и правка
локального хранилища ни на что не влияют — ближайший же раунд вернёт
настоящий баланс.

Битвы и Джекпот с аккаунтом пока недоступны: они ещё не переехали на сервер,
а считать их на устройстве значило бы рисовать себе несуществующие деньги.

## Аккаунт и облачный прогресс

Профиль → «Войти или зарегистрироваться». Логин и пароль хранятся на сервере
(argon2id), в приложение приходит пара токенов: короткий access на 15 минут и
одноразовый refresh на 60 дней. Протухший access обновляется сам.

Адрес сервера зашивается в сборку из секрета `API_DOMAIN`, но его можно
переопределить прямо в приложении — строка «Сервер» на экране аккаунта.
Без адреса игра работает как раньше, полностью офлайн.

Локальное сохранение переносится в облако один раз, кнопкой «Перенести
прогресс в облако». Повторный перенос сервер отклоняет, как и перенос в
аккаунт, где уже сыграны раунды, — иначе импортом можно было бы затирать
себе проигрыши.

## Админ-панель

Открывается вводом кода `MAXADMIN2026` в поле промокода, дальше живёт
в профиле. Умеет выдавать и задавать баланс, выдавать предметы, ставить
уровень и **выпускать промокоды**.

Выпущенный код выглядит как `MX-64R30C1G-5621F` и работает на любом
устройстве без сервера: награда упакована в сам код, рядом лежит
подпись HMAC-SHA256 на общем секрете сборки. Приложение проверяет
подпись локально, поэтому подобрать код нельзя, а вот отозвать
выпущенный — тоже нельзя.

Секрет лежит в клиенте, так что от того, кто разберёт APK, он не
защищает. Для игры на виртуальную валюту этого достаточно; если
понадобятся отзыв кодов, лимиты на активации и учёт по игрокам —
нужен сервер.

## CI

`.github/workflows/build.yml` собирает оба артефакта:

- **Android APK** на ubuntu-latest,
- **Windows EXE** (установщик + portable) на windows-latest.

Файлы лежат в артефактах запуска. Если добавить секреты
`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` —
APK собирается подписанным релизом, иначе отладочным (он тоже ставится на телефон).

Пуш тега `vX.Y.Z` публикует GitHub Release со всеми файлами. То же самое делает
ручной запуск workflow, если указать тег в поле «Тег релиза».
